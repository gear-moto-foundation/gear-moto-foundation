# GEAR brand assets and installation

The approved brand source files were supplied as PNG images:
- `Gear_Logo_Main.png` — full-color horizontal mark on light backgrounds
- `Gear_Logo_Black.png` — black horizontal mark
- `Gear_Logo_White.png` — white horizontal mark for dark backgrounds and sunset hero
- `Gear_G.png`, `Gear_E.png`, `Gear_A.png`, `Gear_R.png` — supporting letter/speedmark art
- `GEAR_Moto_Foundation_BannerLogo.png` — rider-at-sunset photograph

## GitHub / hosting status
GitHub currently contains faithful simplified SVG traces of the white wordmark and G/E/A/R marks plus updated site code. The **original high-resolution PNGs and optimized rider JPEG are included in the downloadable WordPress package**, not yet uploaded to GitHub as binary assets. Do not assume a GitHub clone alone will display the photo or WordPress PNG assets.

**To implement on WestHost:** download the WordPress child theme ZIP from the ChatGPT deliverables and upload it in WordPress → Appearance → Themes → Add New → Upload Theme; parent Blocksy must already be installed. Activate only after making a backup. Add `[gear_homepage]` as a Shortcode block on the static Home page. In Blocksy, use the white logo for dark headers and full-color logo for light backgrounds. No DNS change is needed for this brand upload.

## Image handling
Each optimized website asset is under 2 MB, including the sunset hero JPEG. Preserve readable/SEO-oriented filenames, use descriptive alt text, and verify image dimensions and contrast on mobile.

## Source quality
PNG originals preserve texture and distressed type; the GitHub SVG approximations intentionally simplify texture for small UI placements. Use original PNGs for large-scale wordmarks.
