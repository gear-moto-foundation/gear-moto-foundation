# GEAR Moto Foundation design system

This is the approved visual specification for the Astro website.

## Typography
- Heading family: Barlow Condensed
- H1: 64px / 800 (700 also acceptable)
- H2: 44px / 700
- H3: 32px / 700
- H4: 26px / 600
- H5: 21px / 600
- H6: 17px / 600
- Body: Inter

Responsive heading sizes may scale down at mobile breakpoints.

## Colors
- Primary brand red / links: `#D71920`
- Accent hover / secondary: `#A80F15`
- Base text: `#343A40`
- Headings / dark backgrounds: `#111820`
- Link hover: `#A80F15`
- Border: `#E7EAED`
- Light background: `#F4F5F6`
- White: `#FFFFFF`

Site CSS variables are defined in `src/styles/global.css`.

## Approved images
Use original user-uploaded images in `public/images`. Never delete these assets while refining the site's layout or styling.
