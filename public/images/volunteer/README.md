## Upload standards

- Use JPEG (`.jpg`) with each file **under 2 MB**.
- Upload photos through GitHub’s **Add file → Upload files** on this directory's page.
- Do not delete this README (GitHub does not keep empty directories).
- These images are **illustrative** until genuine, consented GEAR volunteer-event photographs are available.
- Do not depict proposed GEAR events, roles, assistance awards, nonprofit filings or volunteers as already confirmed.
- Once photos are uploaded and approved, update `src/pages/volunteer.astro` to reference the new filenames. Simply uploading files does **not** put them on the website.
